# Квадратные временные ряды четырёх стран

## Состав

Перерендерить временные ряды осадков и задержки доступности для четырёх стран,
представляющих разные масштабы суммарной задержки:

- COL — большая;
- LBR — основной кейс;
- CMR — средняя;
- GAB — малая.

## Компоновка

- Один квадратный PNG с сеткой 2×2.
- Одинаковые пределы осей для сопоставимости стран.
- Синяя линия и левая ось — недельные осадки.
- Красная линия и правая ось — недельная задержка доступности.
- Одна общая легенда снизу; названия стран над панелями.
- Подписи дат показываются только в нижнем ряду, без наложений и обрезки.

## Данные и проверка

Использовать сохранённый `weekly_country_mechanism.csv`, не обрезать исходный PNG.
Проверить квадратный размер, 53 недели для каждой страны, четыре панели, общие
масштабы осей и полностью видимую легенду.

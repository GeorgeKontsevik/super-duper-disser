# Транспонированная матрица Спирмена

## Состав

Перерендерить матрицу корреляций Спирмена с задержкой доступности из сохранённых
результатов экваториального эксперимента. Данные и значения корреляций не менять.

## Ориентация и компоновка

- Строки: авокадо, банан, ананас, манго, плантан.
- Столбцы: воздействие осадков, удалённость по времени, доля дорог без покрытия.
  Для последнего показателя инвертировать знак сохранённых коэффициентов:
  `−0,38 → 0,38` и `−0,50 → 0,50`.
- Длинные названия столбцов выводятся горизонтально в несколько строк.
- Численные значения показываются внутри непустых ячеек; отсутствующие значения
  остаются серыми и без подписи.
- Общая расходящаяся шкала `ρ Спирмена` от −1 до 1 размещается справа.
- Холст имеет отношение сторон 4:3; матрица занимает основную площадь без крупных
  пустых полей и обрезанных подписей.

## Проверка

Проверить физическое отношение сторон PNG, ориентацию 5×3, восемь подписанных
коэффициентов, серые пустые ячейки и полностью видимую цветовую шкалу.

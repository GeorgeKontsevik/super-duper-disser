# Русская двухпанельная схема эксперимента Тихевич

## Цель

Создать единый воспроизводимый PNG из двух исходных QGIS-карт: размещение существующих и дополнительных сервисов и изменение транспортной связности между кварталами.

## Источники

- `itmo-phd-thesis-template-en/images/ch4/optimal_local/tikhevich_new_services.jpeg`;
- `itmo-phd-thesis-template-en/images/ch4/optimal_local/tikhevich_link_improvements.jpeg`.

Геометрия кварталов, сервисов и связей сохраняется из исходных карт. Английские легенды не переносятся.

## Результат

- Скрипт: `scripts/render_tikhevich_russian_map_pair.py`.
- PNG: `itmo-phd-thesis-template-en/images/ch4/optimal_local/tikhevich_russian_map_pair.png`.

## Композиция

На белом широком холсте расположены две равные панели. Карты масштабируются пропорционально без искажения.

Левая панель получает русскую легенду:

- `Существующие сервисы`;
- `Новые сервисы`.

Правая панель получает заголовок легенды `Сокращение времени доступности между кварталами` и интервалы `2–3,8`, `3,8–5,4`, `5,4–8`, `8–10,5`, `10,5–13,2` в исходных цветах.

Подписи панелей:

- `а) Размещение существующих и дополнительных сервисов`;
- `б) Распределение улучшения транспортной связности между кварталами`.

Используется Arial, крупный русский текст, белый фон и исходная цветовая кодировка.

## Проверка

Скрипт должен завершаться успешно и создавать RGB PNG ожидаемого размера. Итоговый PNG проверяется визуально: карты не обрезаны, английский текст отсутствует, русские подписи читаемы, интервалы и цвета легенды совпадают с источником.
